02 · การประมวลผลสัญญาณ

Signal Preprocessing & Normalization Pipeline

ก่อนที่สัญญาณจะถูกส่งเข้าสู่โครงข่ายประสาทเทียม ข้อมูลสัญญาณดิบจะผ่านขั้นตอนการปรับมาตรฐานตามลำดับอย่างเข้มงวด:

ECG Signal Processing Flow
1. Lead Reordering      : [I, II, III, aVR, aVL, aVF, V1, V2, V3, V4, V5, V6]
2. Resampling & Slice    : Resample to fs = 100 Hz, Length N = 1000 points (10.0 s)
3. Bandpass Filtering   : 0.5 – 40.0 Hz Butterworth (ขจัด Baseline Drift & Powerline Noise)
4. Per-lead Z-Score Norm: x_norm = (x - mean) / (std + 1e-6)
5. Tensor Packaging     : Shape = (Batch, 12, 1000) Float32
$$\text{Z-Score Standardization: } \quad x_{i, c}(t) = \frac{x_{i, c}(t) - \mu_{i, c}}{\sigma_{i, c} + 10^{-6}}$$ โดยที่ $i$ คือตัวอย่างที่ป้อนเข้า, $c \in \{1, \dots, 12\}$ คือ Lead แต่ละช่องสัญญาณ

การทำ Z-score แยกราย Lead มีความสำคัญอย่างยิ่ง เพราะช่วยขจัดความต่างของค่าเกน (Voltage Gain) และความต้านทานผิวหนัง (Electrode Contact Impedance) ระหว่างผู้ป่วยและอุปกรณ์แต่ละรุ่น ทำให้ AI โฟกัสเฉพาะรูปร่างคลื่น (Morphology)

03 · สถาปัตยกรรมโครงข่าย

สถาปัตยกรรม 1D-CNN (Deep 1D Convolutional Network)

สถาปัตยกรรมหลักถูกออกแบบให้เป็น Hierarchical 1D-CNN 4 บล็อก เพื่อจับรูปแบบคลื่นไฟฟ้าหัวใจตั้งแต่ระดับความถี่สูง (QRS Spikes, Q-wave) ไปจนถึงระดับคาบเวลายาว (ST segment, T-wave, R-R interval variation)

Layer Breakdown (PyTorch Structure)
Layer / Block Operation Details Kernel / Stride Output Tensor Shape
Input 12-lead ECG Signal — (Batch, 12, 1000)
ConvBlock 1 Conv1d(12→32) → BN → ReLU → Conv1d(32→32) → BN → ReLU → MaxPool1d(2) k=7, s=1 (Batch, 32, 500)
ConvBlock 2 Conv1d(32→64) → BN → ReLU → Conv1d(64→64) → BN → ReLU → MaxPool1d(2) k=7, s=1 (Batch, 64, 250)
ConvBlock 3 Conv1d(64→128) → BN → ReLU → Conv1d(128→128) → BN → ReLU → MaxPool1d(2) k=7, s=1 (Batch, 128, 125)
ConvBlock 4 Conv1d(128→128) → BN → ReLU → Conv1d(128→128) → BN → ReLU → MaxPool1d(2) k=7, s=1 (Batch, 128, 62)
Global Pooling AdaptiveAvgPool1d(1) → Flatten — (Batch, 128)
Classifier Head Dropout(p=0.3) → Linear(128 → 6 classes) — (Batch, 6) Logits

ทำไมต้องใช้ 1D-CNN แทน 2D-CNN หรือ Transformer ?

  • Temporal Continuity: สัญญาณ ECG เป็นข้อมูลอนุกรมเวลาต่อเนื่อง 1 มิติ การใช้ 1D Convolution ที่มี Kernel ขนาด 7 ช่วยดึงสาระสำคัญของช่วงเวลา 70 ms (ความกว้างช่วงปกติของ QRS) ได้อย่างแม่นยำ
  • Low Latency & Energy Efficient: โมเดลมีขนาดเพียง ~1.5 MB รันบน CPU ของเซิร์ฟเวอร์ได้ภายใน 14.2 ms เร็วกว่า Transformer ถึง 10 เท่า และไม่ต้องการ GPU
  • Robustness to Sample Rate: ทนทานต่อสัญญาณรบกวนได้ดีกว่า และไม่เกิด Overfitting จากจำนวน Parameter ที่มากเกินไป
04 · การฝึกฝนและการคำนวณ Loss

Multi-Label Formulation & Binary Cross-Entropy Loss

ในความเป็นจริงทางการแพทย์ ผู้ป่วย 1 คนอาจมีภาวะผิดปกติได้หลายอย่างพร้อมกัน (เช่น เป็นทั้ง MI และ CD หรือ AFIB ร่วมกับ STTC) ระบบจึงใช้การจำแนกแบบ Multi-Label Classification โดยแต่ละคลาสมีโอกาสเกิดอิสระต่อกัน

$$\mathcal{L}_{\text{BCEWithLogits}} = -\frac{1}{C}\sum_{c=1}^{C} \left[ y_c \cdot \log(\sigma(\hat{z}_c)) + (1 - y_c) \cdot \log(1 - \sigma(\hat{z}_c)) \right]$$ โดยที่ $\sigma(z) = \frac{1}{1 + e^{-z}}$ คือ Sigmoid Activation และ $C = 6$ คือจำนวนคลาส

การตั้งค่า Hyperparameters ในการฝึกฝนจริง:

  • Optimizer: AdamW ($\beta_1=0.9, \beta_2=0.999$, Weight Decay $= 10^{-4}$)
  • Learning Rate: Initial LR $= 10^{-3}$ ร่วมกับ Cosine Annealing Scheduler
  • Batch Size: 64 ตัวอย่าง
  • Regularization: Dropout Rate $= 0.30$ + Batch Normalization
  • Target Checkpoint: เลือก Checkpoint ที่ได้ค่า val_macro_auc สูงที่สุดบน Fold 9

Clinical Safety Gate (classification_eligible)

เพื่อความปลอดภัยสูงสุดของผู้ป่วย ระบบจะไม่ฝืนส่งข้อมูลเข้าโมเดล AI หากไม่ผ่านเกณฑ์ 3 ข้อต่อไปนี้:

  1. ครบ 12 Leads มาตรฐาน: มีครบ I, II, III, aVR, aVL, aVF, V1-V6
  2. ความยาวสัญญาณเพียงพอ: ไม่ต่ำกว่า 5–10 วินาที
