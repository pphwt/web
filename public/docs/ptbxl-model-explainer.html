01 · สัญญาณคลื่นไฟฟ้าหัวใจจริง และชุดข้อมูล PTB-XL

12-Lead ECG Paper Strip จากผู้ป่วยจริง & การแบ่ง 10-Fold

สัญญาณคลื่นไฟฟ้าหัวใจ (ECG) มาตรฐานประกอบด้วย 12 ช่องสัญญาณ (12 Leads) ที่มองหัวใจจาก 12 ทิศทางรอบด้าน:

  • Limb Leads (I, II, III, aVR, aVL, aVF): บันทึกความต่างศักย์ในระนาบแนวดิ่ง (Frontal Plane) มองผนังหัวใจด้านล่าง (Inferior) และด้านข้าง (Lateral)
  • Precordial Leads (V1, V2, V3, V4, V5, V6): บันทึกความต่างศักย์ในระนาบแนวนอนรอบทรวงอก (Horizontal Plane) มองกั้นหัวใจ (Septal) และผนังหัวใจด้านหน้า (Anterior)
Figure 1: Real 12-Lead ECG Clinical Recording (PTB-XL Patient: 00001_hr) Standard 25 mm/s · 10 mm/mV
รูปที่ 1 (ภาพข้อมูลจริง): แผ่นบันทึก ECG 12 Leads ของผู้ป่วยจริงจากฐานข้อมูล PTB-XL (PhysioNet) บนตารางกราฟมาตรฐานการแพทย์ ช่องเล็ก 0.04 วินาที (1 mm) และช่องใหญ่ 0.20 วินาที (5 mm) แสดงการทำงานพร้อมกันทั้ง 12 ช่องสัญญาณ

02 · การเปรียบเทียบพยาธิสภาพของโรคจริง

วิเคราะห์เปรียบเทียบคลื่น ECG จริงใน 4 กลุ่มโรคสำคัญ

ด้านล่างนี้คือข้อมูลคลื่นจริงของ Lead II (ความยาว 4.0 วินาที) จากผู้ป่วย 4 รายในฐานข้อมูล PTB-XL ที่แสดงพยาธิสภาพแตกต่างกันอย่างชัดเจน:

Figure 2: Real Clinical Waveform Comparison Across 4 Pathologies PTB-XL Patients (Lead II Strip)
รูปที่ 2 (ภาพคลื่นจริง): เปรียบเทียบคลื่นจริง 4 เคส:
  • NORM (เขียว): คลื่น P, QRS, T สมบูรณ์ อัตราเต้น 75 bpm ปกติ
  • MI (แดง): ภาวะกล้ามเนื้อหัวใจตายเฉียบพลัน (Acute Inferior STEMI) สังเกต ST-segment ยกสูงอย่างรุนแรง
  • AFIB (ส้ม): ภาวะหัวใจห้องบนสั่นพลิ้ว คลื่น P หายไป และจังหวะการบีบตัวไม่สม่ำเสมอ (Irregular R-R)
  • CD (ม่วง): การนำไฟฟ้าหัวใจช้าลงผิดปกติ (ILBBB) ส่งผลให้ช่วง QRS กว้างกว่า 120 ms และมียอดคลื่นบาก (Notched)
03 · การประมวลผลสัญญาณและขจัดสัญญาณรบกวน

กระบวนการเตรียมข้อมูลสัญญาณ (Preprocessing Pipeline)

คลื่น ECG ที่บันทึกจากผิวหนังมักปนเปื้อนด้วยคลื่นไฟฟ้ากระแสสลับ $50/60\text{ Hz}$ และการเคลื่อนไหวของผู้ป่วย (Baseline Drift) จึงต้องผ่านกระบวนการกรอง 3 ขั้นตอน:

Figure 3: Step-by-Step ECG Signal Filtering & Normalization Butterworth Bandpass + Z-Score
รูปที่ 3 (ผลการประมวลผลจริง): (1) สัญญาณดิบที่มีสัญญาณรบกวน $\rightarrow$ (2) ผ่าน Bandpass Filter 0.5–40.0 Hz ตัดคลื่นกวน $\rightarrow$ (3) ปรับ Z-Score Normalization $(\mu=0.0, \sigma=1.0)$ ราย Lead เพื่อให้ขนาด Amplitude มีมาตรฐานเดียวกันทุกเคส
$$\text{Z-Score Standardization: } \quad x_{\text{norm}}(t) = \frac{x(t) - \mu_{\text{lead}}}{\sigma_{\text{lead}} + 10^{-6}}$$

ขั้นตอนที่ 1: การ Export โมเดล PyTorch → ONNX (Model Serialization) Python / PyTorch

หลังจากเทรนโมเดลด้วย PyTorch เสร็จ เราจะทำการ Export โครงสร้างและน้ำหนัก (Weights) ออกเป็นไฟล์ ptbxl_classifier.onnx เพื่อให้ทำงานบน CPU ได้เร็วขึ้น 4–5 เท่า และไม่ต้องติดตั้ง PyTorch ใน Production Container: 

# train-model-EP/scripts/export_onnx.py
import torch
from network import PTBXLClassifier1D

# 1. โหลดโมเดล PyTorch และนำ Weights ที่เทรนได้ใส่เข้าไป
model = PTBXLClassifier1D(num_classes=6)
checkpoint = torch.load("checkpoints/best_ptbxl_epoch6.pt", map_location="cpu")
model.load_state_dict(checkpoint["model_state_dict"])
model.eval()

# 2. สร้าง Dummy Tensor จำลองมิติข้อมูลนำเข้า (Batch=1, Leads=12, Samples=1000)
dummy_input = torch.randn(1, 12, 1000, dtype=torch.float32)

# 3. Export เป็น ONNX Model พร้อมกำหนด Dynamic Batch Size
torch.onnx.export(
    model,
    dummy_input,
    "checkpoints/ptbxl_classifier.onnx",
    input_names=["ecg_leads"],
    output_names=["logits"],
    dynamic_axes={"ecg_leads": {0: "batch_size"}, "logits": {0: "batch_size"}},
    opset_version=14
)
print("Export ONNX Model สำเร็จเรียบร้อย!")

# model_api/schemas.py
from pydantic import BaseModel, Field
from typing import Dict, List, Optional

class EcgInferenceRequest(BaseModel):
    lead_signals: List[List[float]] = Field(
        ..., 
        description="เมทริกซ์ 12 ลีด: ขนาด (12 x N_SAMPLES)"
    )
    lead_names: Optional[List[str]] = Field(
        default=["I","II","III","AVR","AVL","AVF","V1","V2","V3","V4","V5","V6"]
    )
    sampling_rate: int = Field(default=100, description="ความถี่สุ่มสัญญาณ (Hz)")

    NORM: float = Field(..., description="ความน่าจะเป็น: คลื่นปกติ (0.0 - 1.0)")
    MI: float   = Field(..., description="ความน่าจะเป็น: กล้ามเนื้อหัวใจตายเฉียบพลัน")
    STTC: float = Field(..., description="ความน่าจะเป็น: คลื่น ST-T เปลี่ยนแปลง")
    CD: float   = Field(..., description="ความน่าจะเป็น: การนำไฟฟ้าหัวใจช้าลง")
    HYP: float  = Field(..., description="ความน่าจะเป็น: กล้ามเนื้อหัวใจหนาตัว")
    AFIB: float = Field(..., description="ความน่าจะเป็น: หัวใจห้องบนสั่นพลิ้ว")

class EcgInferenceResponse(BaseModel):
    success: bool
    probabilities: DiseaseProbabilities
    primary_finding: str
    triage_flag: str  # RED_FLAG, YELLOW_FLAG, GREEN_FLAG
    inference_time_ms: float
ขั้นตอนที่ 3: การเขียนฟังก์ชัน Preprocessing (Align Leads & Z-Score) NumPy / Signal

ปรับขนาดมิติสัญญาณให้ได้ $(1, 12, 1000)$ ตรงตามมาตรฐาน และปรับ Z-Score Standardization ราย Lead: 

# app/ecg/preprocessing.py
import numpy as np

TARGET_SAMPLES = 1000
CANONICAL_LEADS = ["I", "II", "III", "AVR", "AVL", "AVF", "V1", "V2", "V3", "V4", "V5", "V6"]

def preprocess_ecg_matrix(signals: np.ndarray, lead_names: list) -> np.ndarray:
    """
    แปลงสัญญาณนำเข้าให้มีขนาด (1, 12, 1000) float32 พร้อม Z-score normalization
    """
    # 1. เรียงลำดับ Lead ให้ตรงตามมาตรฐาน 12 ลีด
    names_upper = [str(n).strip().upper() for n in lead_names]
    lead_indices = [names_upper.index(l) for l in CANONICAL_LEADS]
    reordered_sig = signals[lead_indices, :] # (12, T)

    # 2. Resample แกนเวลาให้เท่ากับ 1,000 จุด (10.0 วินาที)
    T = reordered_sig.shape[1]
    xp = np.arange(T)
    xnew = np.linspace(0, T - 1, TARGET_SAMPLES)
    resampled = np.stack([np.interp(xnew, xp, reordered_sig[c, :]) for c in range(12)], axis=0) # (12, 1000)

    # 3. คำนวณ Z-Score Normalization ราย Lead
    means = np.mean(resampled, axis=1, keepdims=True)
    stds = np.std(resampled, axis=1, keepdims=True) + 1e-6
    normalized = (resampled - means) / stds

    # 4. เพิ่มมิติ Batch -> (1, 12, 1000)
    return np.expand_dims(normalized.astype(np.float32), axis=0)
ขั้นตอนที่ 4: การสร้าง ONNX Runtime Session & Inference Engine ONNX Runtime

โหลดโมเดลเข้าหน่วยความจำด้วย LRU Cache เพื่อให้โมเดลพร้อมรันทันทีโดยไม่ต้องโหลดไฟล์ซ้ำในทุก Request: 

# app/ecg/engine.py
import onnxruntime as ort
import numpy as np
from functools import lru_cache

@lru_cache(maxsize=1)
def get_onnx_session(model_path: str = "checkpoints/ptbxl_classifier.onnx"):
    """โหลดและแคช ONNX Runtime Session บน CPU"""
    opts = ort.SessionOptions()
    opts.intra_op_num_threads = 2
    opts.graph_optimization_level = ort.GraphOptimizationLevel.ORT_ENABLE_ALL
    session = ort.InferenceSession(model_path, sess_options=opts, providers=["CPUExecutionProvider"])
    input_name = session.get_inputs()[0].name
    return session, input_name

def run_ptbxl_inference(tensor_12x1000: np.ndarray) -> np.ndarray:
    """รัน Inference และคำนวณ Sigmoid Activation ออกมาเป็นค่าความน่าจะเป็น (0.0 - 1.0)"""
    session, input_name = get_onnx_session()
    raw_logits = session.run(None, {input_name: tensor_12x1000})[0] # (1, 6)
    
    # คำนวณ Sigmoid: P = 1 / (1 + exp(-z))
    probabilities = 1.0 / (1.0 + np.exp(-raw_logits[0]))
    return probabilities
ขั้นตอนที่ 5 & 6: การเขียน FastAPI Endpoint & Triage Decision Protocol FastAPI App

เปิด Route Endpoint /api/v1/predict/ptbxl พร้อมการวัดเวลา Latency และ Safety Triage: 

# app/main.py
from fastapi import FastAPI, HTTPException
import time
import numpy as np
from schemas import EcgInferenceRequest, EcgInferenceResponse, DiseaseProbabilities
from preprocessing import preprocess_ecg_matrix
from engine import run_ptbxl_inference

app = FastAPI(title="Bioelectric PTB-XL ECG Diagnostic API", version="1.0.0")

LABELS = ["NORM", "MI", "STTC", "CD", "HYP", "AFIB"]

@app.post("/api/v1/predict/ptbxl", response_model=EcgInferenceResponse)
async def predict_ecg(payload: EcgInferenceRequest):
    t_start = time.perf_counter()
    try:
        # 1. แปลง Input Array เป็น NumPy
        raw_signals = np.array(payload.lead_signals, dtype=np.float32)
        if raw_signals.shape[0] != 12:
            raise HTTPException(status_code=400, detail="จำเป็นต้องมีสัญญาณครบทั้ง 12 ลีด")

        # 2. รัน Preprocessing
        input_tensor = preprocess_ecg_matrix(raw_signals, payload.lead_names)

        # 3. รัน ONNX Inference
        probs = run_ptbxl_inference(input_tensor)
        prob_dict = {label: float(probs[i]) for i, label in enumerate(LABELS)}

        # 4. ประเมินระดับความเร่งด่วน (Triage Protocol)
        if prob_dict["MI"] >= 0.50 or prob_dict["AFIB"] >= 0.70:
            triage_flag = "RED_FLAG"
            primary_finding = "สงสัยภาวะกล้ามเนื้อหัวใจตายเฉียบพลันหรือหัวใจเต้นผิดจังหวะวิกฤต"
        elif prob_dict["STTC"] >= 0.50 or prob_dict["CD"] >= 0.50 or prob_dict["HYP"] >= 0.50:
            triage_flag = "YELLOW_FLAG"
            primary_finding = "พบความผิดปกติของคลื่นไฟฟ้าหัวใจ ควรส่งต่อพบแพทย์เฉพาะทาง"
        else:
            triage_flag = "GREEN_FLAG"
            primary_finding = "คลื่นไฟฟ้าหัวใจอยู่ในเกณฑ์ปกติ (Normal Sinus Rhythm)"

        elapsed_ms = (time.perf_counter() - t_start) * 1000.0

        return EcgInferenceResponse(
            success=True,
            probabilities=DiseaseProbabilities(**prob_dict),
            primary_finding=primary_finding,
            triage_flag=triage_flag,
            inference_time_ms=round(elapsed_ms, 2)
        )
    except Exception as e:
        raise HTTPException(status_code=500, detail=f"เกิดข้อผิดพลาดในการประมวลผล: {str(e)}")

09 · คู่มือเกณฑ์ค่าปกติทางการแพทย์ (ECG Measurement Cheat-Sheet)

สรุปเกณฑ์มาตรฐานและการวัดค่าช่วงคลื่น (Clinical Intervals)

สรุปเกณฑ์มาตรฐานสากลที่แพทย์และระบบ AI ใช้ในการประเมินความผิดปกติของคลื่นไฟฟ้าหัวใจ:

พารามิเตอร์ (Parameter) ช่วงค่าปกติ (Normal Range) ความหมายเมื่อผิดปกติ (Clinical Significance) สูตร / วิธีการวัด
Heart Rate (อัตราเต้น) 60 – 100 ครั้ง/นาที (bpm) < 60: Bradycardia (เต้นช้า)
> 100: Tachycardia (เต้นเร็ว)		 $HR = \frac{1500}{\text{จำนวนช่องเล็กระหว่าง R-R}}$
PR Interval 120 – 200 มิลลิวินาที (3–5 ช่องเล็ก) > 200 ms: First-degree AV Block
< 120 ms: WPW Syndrome (Pre-excitation)		 จุดเริ่มคลื่น P ถึงจุดเริ่ม QRS Complex
QRS Duration 70 – 110 มิลลิวินาที (< 3 ช่องเล็ก) > 120 ms: Bundle Branch Block (LBBB / RBBB) หรือ Ventricular Origin จุดเริ่มคลื่น Q ถึงจุดสิ้นสุดคลื่น S
QTc (Corrected QT) 350 – 450 มิลลิวินาที > 460 ms (ช) / > 470 ms (ญ): เสี่ยงต่อ Arrhythmia / Torsades de Pointes $\text{QTc} = \frac{\text{QT}}{\sqrt{\text{RR}}}$ (สูตร Bazett)
Cardiac Axis (แกนไฟฟ้า) -30° ถึง +90° (Normal Axis) < -30°: Left Axis Deviation (LAD)
> +90°: Right Axis Deviation (RAD)		 ประเมินทิศทาง Vector สุทธิใน Lead I และ aVF
Sokolow-Lyon (LVH) < 35 มิลลิเมตร (mV) $\ge 35\text{ mm}$: บ่งชี้ภาวะกล้ามเนื้อหัวใจห้องล่างซ้ายโต (LVH) $S_{\text{V1}} + R_{\text{V5/V6}} \ge 35\text{ mm}$

รูปที่ 8 (โฟลว์การทำงานรวมทั้งระบบ): จากสัญญาณคลื่นไฟฟ้าหัวใจ 2D เข้าสู่การจำแนกโรคด้วย PTB-XL 1D-CNN แล้วส่งพิกัดไฟฟ้าไปยัง PINN 3D Localizer เพื่อแสดงผลเป็นแผนที่ความร้อน 3 มิติบนกล้ามเนื้อหัวใจจริง
🔴 Red Flag — ภาวะฉุกเฉินวิกฤต (Immediate Emergency Transfer)
เงื่อนไข: ตรวจพบ Acute STEMI (MI Probability > 0.60) หรือ High-rate AFIB ร่วมกับความดันโลหิตผิดปกติ
แนวทางปฏิบัติ: ส่งตัวผู้ป่วยเข้าห้องฉุกเฉิน (ER) ทันที เพื่อเข้าสู่กระบวนการฉีดสีสวนหลอดเลือดหัวใจ (Primary PCI) ภายใน 90 นาที (Door-to-Balloon Time)
🟡 Yellow Flag — เฝ้าระวังและนัดพบแพทย์เฉพาะทาง (Specialist Referral)
เงื่อนไข: ตรวจพบ ST-T Abnormality (STTC), Conduction Disturbance (CD / LBBB), หรือ Hypertrophy (HYP)
แนวทางปฏิบัติ: นัดหมายแพทย์อายุรกรรมหัวใจ ตรวจเลือดดูระดับ Cardiac Enzymes (Troponin-T) และตรวจคลื่นเสียงสะท้อนหัวใจ (Echocardiogram)
🟢 Green Flag — ปกติ (Routine Follow-up)
เงื่อนไข: คลื่น Normal Sinus Rhythm (NORM Probability > 0.85) และไม่มีอาการเจ็บแน่นหน้าอก
แนวทางปฏิบัติ: บันทึกประวัติในระบบสุขภาพชุมชน นัดตรวจสุขภาพประจำปีตามรอบปกติ
